# 自选基金盘中估值

脚本按自选基金代码查询盘中估算涨跌。编辑 `funds.json`，填写自己的 6 位基金代码：

```json
[
  "000001",
  "510300"
]
```

运行一次：

```bash
python3 fund_watch.py
```

持续刷新（默认每 60 秒）：

```bash
python3 fund_watch.py --watch
```

可以指定配置文件和刷新间隔，例如：

```bash
python3 fund_watch.py -c ~/funds.json --watch --interval 30
```

## 数据源

脚本按顺序使用两家数据源：

1. 天天基金 / 东方财富的批量估值接口。
2. 基金速查网的单基金模型估值接口，仅在主源没有估值时调用。

备用源根据公开持仓和市场行情估算，可能与最终净值有偏差。脚本只接受估值日期为当天的数据，并在结果中显示数据源和更新时间；若备用源返回旧数据，会显示其数据日期而不把旧值当成盘中估值。接口是公开网页服务，可能变更或限流。

盘中涨跌不是基金公司公布的正式净值，最终结果以基金公司公布的净值为准。

## 证书错误排查

脚本会使用系统 CA 证书，若已安装 `certifi` 也会尝试读取它。若仍遇到 `CERTIFICATE_VERIFY_FAILED`，可安装证书包：

```bash
python3 -m pip install --user certifi
```

如果网络经过公司 HTTPS 代理，请将代理 CA 证书的 PEM 文件路径设为 `SSL_CERT_FILE` 后再运行。脚本不会关闭 HTTPS 证书校验。
